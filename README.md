# Car Rental Management Application

## About

This is a vehicle rental management application developed using C#.Net with a SQL Server backend. The application facilitates the management of car rentals, including vehicle inventory, customer information, rental contracts, and payment tracking. It is designed to help car rental businesses streamline their operations efficiently.

## Features

- Manage vehicle inventory with details such as make, model, availability, and rental rates.
- Customer management including personal details and rental history.
- Create and manage rental contracts with start and end dates.
- Track rental payments and statuses.
- Integration with SQL Server for secure and efficient data storage.

## Technologies Used

- C#.Net for the application logic and interface.
- SQL Server for the database management.

## Setup Instructions

1. Clone the repository:
git clone `https://github.com/Nizar7kabbaj/car-rental-app.git`


2. Open the solution in Visual Studio.

3. Configure the SQL Server connection string in the application's configuration file.

4. Set up the SQL Server database using the provided scripts or your own schema.

5. Build and run the application.
